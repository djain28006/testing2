# testing2 - VedicVibe Tours & Travels

Luxury & Pilgrimage Tours Platform built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and OpenAI GPT-4o-mini integration.

## Features
- Mobile-first luxury UI with deep teal ocean theme & saffron pilgrimage mode switch
- Real-time OpenAI GPT-4o-mini WhatsApp Booking Agent
- Multi-step booking flow wizard & boarding pass voucher generator
- Full Admin Panel with Revenue Charts, WhatsApp Inbox, Seat Heatmap Calendar & Quotation Builder
- Deployable to Render and Netlify
